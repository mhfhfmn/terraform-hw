4. В манифесте допущенно 4 ошибки

Первая ошибка:
```
╷
│ Error: Missing name for resource
│ 
│   on main.tf line 23, in resource "docker_image":
│   23: resource "docker_image" {
│ 
│ All resource blocks must have 2 labels (type, name).
╵
```
сообщает о том, что в указанный ресурсе отсутствует локальный идентификатор(лейбл). Исходя из кода ниже `image = docker_image.nginx.image_id` локальное имя должно быть `nginx`.

Вторая ошибка:
```
╷
│ Error: Invalid resource name
│ 
│   on main.tf line 28, in resource "docker_container" "1nginx":
│   28: resource "docker_container" "1nginx" {
│ 
│ A name must start with a letter or underscore and may contain only letters, digits, underscores, and dashes.
╵
```
сообщает о том, что у ресурса неправильный локальный лейбл, в данном случае tarrafom не устраивает, что лейбл начинается с цифры. Исправим название на `"nginx"`

Третья ошибка:
```
╷
│ Error: Reference to undeclared resource
│ 
│   on main.tf line 30, in resource "docker_container" "nginx_1":
│   30:   name  = "example_${random_password.random_string_FAKE.resulT}"
│ 
│ A managed resource "random_password" "random_string_FAKE" has not been declared in the root module.
╵
```
сообщает о том, что не был объхявлен ресурс `random_string_FAKE`, в нашем коде он называется `random_string`, сотрем лишнее.

Третья ошибка:
```
╷
│ Error: Unsupported attribute
│ 
│   on main.tf line 30, in resource "docker_container" "nginx":
│   30:   name  = "example_${random_password.random_string.resulT}"
│ 
│ This object has no argument, nested block, or exported attribute named "resulT". Did you mean "result"?
╵
```
сообщает о том, что допущена опечатка в слове result, заглавную T необходимо заменить на строчную t.

Ключ `-auto-approve` может быть опасен в случае неправильной конфигурации при правильно синтаксисе манифеста, без этого ключа terraform выводит список предполагаемых изменений при применении, который мы можем просмотреть и убедиться, что все данные внесены корректно, при использовании данного ключа, такая возможность отсутствует, изменения применяются сразу после выполнения команды.
Но при всем при этом, данный ключ обязателен в процессах автоматизации развертывания, т.к. без него terraform ждет ввода пользователя.
